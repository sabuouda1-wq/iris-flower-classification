# Iris Flower Classification 🌸

## About the Project
This is my first Machine Learning project using Python. I trained a K-Nearest Neighbors (KNN) model to classify Iris flowers based on their measurements.

## Dataset
The project uses the Iris dataset from Scikit-learn, which contains 150 samples and 3 flower species.

## Tools and Libraries
- Python
- Pandas
- Scikit-learn
- Google Colab

## Project Steps
1. Load and explore the dataset.
2. Separate features and target labels.
3. Split the data into training and testing sets.
4. Train a KNN classification model.
5. Evaluate the model using accuracy.
6. Predict the species of a new flower.

## Results
The model achieved 100% accuracy on the test set in this experiment.

## What I Learned
This project helped me practice the basic steps of building and evaluating a Machine Learning model.
